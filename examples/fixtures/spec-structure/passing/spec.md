# Feature Specification: Widget Export

**Feature Branch**: `fixture/passing`

## User Scenarios & Testing

A user exports their widget list to CSV from the settings page.

## Requirements

### Functional Requirements

- **FR-001**: The system MUST export the widget list as a CSV file.
- **FR-002**: The export MUST include the widget name and creation date columns.

## Success Criteria

- Export of 1,000 widgets completes and the file opens in a spreadsheet tool.
